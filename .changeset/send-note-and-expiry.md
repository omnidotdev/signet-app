Sending a document now asks for an optional note to signers and how long the request stays open (120 days by default). Signers see the note and the deadline, an expired or canceled link says so up front, and a signer waiting on others is told the final copy comes by email instead of being offered a download that is not ready yet. Documents show when they expire and an "Expired" status
